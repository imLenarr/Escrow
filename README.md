# Freelance Escrow DApp

เว็บแอปพลิเคชันสำหรับพักเงินค่าจ้างระหว่างผู้ว่าจ้างและฟรีแลนซ์ด้วย Smart Contract บน Ethereum ผู้ว่าจ้างฝากเงินเข้าสัญญา ฟรีแลนซ์ส่งข้อมูลอ้างอิงผลงาน และผู้ว่าจ้างอนุมัติให้สัญญาโอนเงินแก่ฟรีแลนซ์

## ความสามารถของระบบ

- เชื่อมต่อกระเป๋า MetaMask และสัญญาที่ระบุด้วย Contract Address
- ผู้ว่าจ้างฝากเงินตามจำนวนที่กำหนดไว้ในสัญญา
- ฟรีแลนซ์บันทึก URL หรือข้อมูลอ้างอิงผลงานลงในสัญญา
- ผู้ว่าจ้างตรวจรับงานและอนุมัติการจ่ายเงิน
- จำกัดสิทธิ์และลำดับการทำรายการด้วยเงื่อนไขใน Smart Contract
- รอการยืนยันธุรกรรมก่อนแจ้งผลสำเร็จบนหน้าเว็บ

## ลำดับการทำงาน

```text
Created → Funded → WorkSubmitted → Completed
           ฝากเงิน       ส่งงาน         อนุมัติและจ่ายเงิน
```

| สถานะ | ความหมาย |
| --- | --- |
| `Created` | สัญญาถูกสร้างและรอรับเงินจากผู้ว่าจ้าง |
| `Funded` | สัญญารับเงินค่าจ้างครบตามจำนวนแล้ว |
| `WorkSubmitted` | ฟรีแลนซ์ส่งข้อมูลอ้างอิงผลงานแล้ว |
| `Completed` | ผู้ว่าจ้างอนุมัติและโอนเงินให้ฟรีแลนซ์สำเร็จ |

## Smart Contract

สัญญา `FreelanceEscrow` ในไฟล์ `Escrow.sol` กำหนดให้บัญชีที่ Deploy เป็นผู้ว่าจ้าง (`employer`) โดยรับข้อมูลเริ่มต้นสามรายการ:

| พารามิเตอร์ | รายละเอียด |
| --- | --- |
| `_freelancer` | แอดเดรสกระเป๋าที่มีสิทธิ์ส่งงานและรับค่าจ้าง |
| `_projectName` | ชื่อโปรเจกต์ |
| `_amount` | จำนวนค่าจ้างในหน่วย wei |

### ฟังก์ชันหลัก

| ฟังก์ชัน | ผู้มีสิทธิ์เรียก | การทำงาน |
| --- | --- | --- |
| `depositPayment()` | ผู้ว่าจ้าง | ฝาก ETH ตรงตามจำนวนค่าจ้างขณะอยู่ในสถานะ Created |
| `submitWork(string)` | ฟรีแลนซ์ | บันทึกข้อมูลอ้างอิงผลงานขณะอยู่ในสถานะ Funded |
| `approveAndRelease()` | ผู้ว่าจ้าง | อนุมัติงานและโอนค่าจ้างขณะอยู่ในสถานะ WorkSubmitted |

ข้อมูลโปรเจกต์ คู่สัญญา จำนวนค่าจ้าง สถานะ และข้อมูลอ้างอิงผลงานสามารถอ่านผ่านตัวแปร public ของสัญญาได้

## เทคโนโลยี

- **Solidity** — เงื่อนไขการพักเงินและจ่ายค่าจ้าง
- **HTML และ JavaScript** — หน้าเว็บและการเรียกใช้งานสัญญา
- **Tailwind CSS** — รูปแบบส่วนติดต่อผู้ใช้ผ่าน CDN
- **ethers.js 5.7.2** — เชื่อมต่อกระเป๋าและส่งธุรกรรม
- **MetaMask** — อนุญาตเชื่อมต่อบัญชีและยืนยันรายการ

## การใช้งาน

เปิด `Escrow.html` ผ่านเว็บเซิร์ฟเวอร์ในเบราว์เซอร์ที่มี MetaMask ระบุ Contract Address ของสัญญา FreelanceEscrow ที่ Deploy แล้ว และเชื่อมต่อกระเป๋าบนเครือข่ายเดียวกับสัญญา ผู้ว่าจ้างใช้บัญชีที่ Deploy สำหรับฝากเงินและอนุมัติ ส่วนฟรีแลนซ์ใช้บัญชีที่กำหนดไว้ตอนสร้างสัญญาสำหรับส่งงาน

หน้าเว็บอ่านจำนวนเงินจากสัญญาเพื่อส่งเงินฝากให้ตรงตามค่าจ้าง การทำรายการแต่ละครั้งต้องยืนยันใน MetaMask และมี ETH บนเครือข่ายนั้นสำหรับค่า gas หน้าเว็บโหลด Tailwind CSS และ ethers.js จาก CDN จึงต้องใช้อินเทอร์เน็ต

## ขอบเขตของรุ่นปัจจุบัน

- หนึ่งสัญญารองรับหนึ่งโปรเจกต์ ผู้ว่าจ้างหนึ่งบัญชี และฟรีแลนซ์หนึ่งบัญชี
- ไม่มีฟังก์ชันยกเลิก คืนเงิน กำหนดเส้นตาย หรือระงับข้อพิพาท แม้มีค่า `Disputed` ใน enum แต่ยังไม่มีฟังก์ชันเปลี่ยนเข้าสู่สถานะนี้
- การส่งงานเก็บเฉพาะข้อความอ้างอิงบนบล็อกเชน ไม่มีระบบอัปโหลดไฟล์หรือตรวจสอบเนื้อหาผลงาน
- หน้าเว็บยังไม่ตรวจสอบเครือข่ายหรืออัปเดตการเชื่อมต่ออัตโนมัติเมื่อเปลี่ยนบัญชี ควรโหลดหน้าเว็บและเชื่อมต่อใหม่หลังเปลี่ยนบัญชีหรือเครือข่าย
- ยังไม่ได้ยืนยันการทำงานครบวงจรด้วยธุรกรรมจริงในการอัปโหลดครั้งนี้
